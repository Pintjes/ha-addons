No target yet

Open the Configuration tab of the add-on, set target_url (for example http://192.168.1.10:8000) and restart the add-on.

If an address is already set, it is not valid: the reason is in the Log tab.

Pas encore de cible

Ouvrez l'onglet Configuration de l'add-on, renseignez target_url (par exemple http://192.168.1.10:8000) et redémarrez l'add-on.

Si une adresse est déjà renseignée, elle n'est pas valide : la raison est dans l'onglet Journal.
